# Northfork Precision, a fictional shop

Northfork and the customers, people and machines in these files are made up.

Northfork is a two-cell CNC job shop. The files cover 13 production days, November 9 to 25, 2026.
Mismatches and spreadsheet faults are planted in them, so you can see what Plant Watch finds.

| Folder | What it holds |
|---|---|
| `plant/erp` | Items, sales orders and work orders |
| `plant/exports` | Daily MES output, downtime and planning files, reason codes, and the maintenance log |
| `plant/spreadsheets` | The supervisor's shift log and a maintenance tracker, with formulas |
| `plant/reports` | Two weekly OEE packs, as PDFs |
| `linked` | A daily summary that stands in for a linked report |

To try it, copy this folder somewhere you can write, open it in Claude, and say "Set up Plant Watch."
