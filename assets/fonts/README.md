Fonts for the Metric Mismatch Report, embedded so a report loads nothing from a network.

- `display-800.ttf`: a Latin subset of Archivo ExtraBold. License: `OFL-Archivo.txt`.
- `text-400.ttf`, `text-600.ttf`: Latin subsets of IBM Plex Sans, renamed because the license reserves the name. License: `OFL-Plex.txt`.
