What to expect

What it finds, and what it doesn't do

What it finds

  • Numbers that disagree across systems. OEE says one thing in the MES and another in the spreadsheet.
  • Definitions that don't match. Same name, different metric. Downtime with or without changeovers, for example.
  • Spreadsheet errors. Broken formulas, typed-over numbers, and ranges that stopped growing.
  • Reports that drifted from the data. A weekly pack that no longer ties back to its exports.

The findings land in one Metric Mismatch Report. Each finding names the file, page or cell it came from. It opens with a score: are you ready for AI agents?

What it doesn't do

  • It doesn't send your files or results. No account or telemetry. Its code makes no network calls.
  • It doesn't change your source data. Results go in their own plant-watch folder.
  • It doesn't decide what your metrics mean. It asks you and records your answer.

Claude processes what you share. That happens under your Claude plan's terms. Plant Watch adds no other destination. If you give it a SharePoint or OneDrive link, Claude reads that report through your own Microsoft 365 connection.

About two minutes

Install it

1
Download. Get plant-watch.zip from humagined.ai/plantwatch. Don't unzip it.
2
Open Plugins. In the Claude desktop app, choose Customize, then Plugins.
3
Upload it. Choose Add, then Upload plugin, and select the zip. Claude reminds you to install only plugins you trust. That's normal.
4
Pick a working folder. Start a task in a folder Plant Watch can use.

Labels can change. If one looks different, use the upload option on the Plugins page.

Can't upload it? Send this to your IT team

Plant Watch is a free, open source Claude plugin under Apache 2.0. If your company manages Claude, an admin may need to add it.

  • The code is open to review at github.com/humagined/plant-watch.
  • It runs on the Python standard library. Its code makes no network calls.
  • It reads the files people point it at. It writes results in a plant-watch folder.
  • Report links are optional. They use the person's own Microsoft 365 connection.
  • Report security problems privately, as SECURITY.md explains.

Your first run

Try the synthetic shop

Northfork Precision is a fictional shop that comes in the download. You don't need your own data yet.

1
Say "Set up Plant Watch with the synthetic shop."
2
Check the list of sources. Say yes if it looks right.
3
Say what each shared metric should mean. "Not settled" is a fine answer.
4
Open the Metric Mismatch Report.

Then use your own data

1
Put copies of a few exports, spreadsheets and report PDFs in one folder.
2
Say "Set up Plant Watch" and name that folder.
3
Have the person who owns each metric nearby. Plant Watch asks who is accountable.
4
Check its findings before you act on them.
